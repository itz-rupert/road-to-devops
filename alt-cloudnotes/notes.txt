** CLOUD ENGINEERING NOTES (Week One)

- The software Development life cycle is a structured, repeatable process that development teams use to design, build and maintain software. Its a cycle that explains what each professional in a development team does till the application goes from the raw stage to the final stage.
- Stage 1-6 include planning (deciding what is what and how they should be), analysis (determining how customers will interact with the platform, infrastructure you will be using etc.), design(how your plan looks like), implementation( making sure your code is working), testing and integration (testing in like sandbox environments to ensure that all is working fine), maintenance ( ensuring that bugs are fixed and improving the system).
- There are several environments like sandbox or dev environment, fail over environment is a backup environment setup that is used when the live environment is down (so it is a replica of the live), Live environment is for catering to the end users, staging environment is for internal testing like QA testers.
- System design is about answering the question how do we build an application so it works for millions of users and doesn't break under pressure.
-  The /dev directory shows the different devices that are connected to our system.
- Package index is a database of available packages and it is generally located in the /etc/apt/sources.list and /etc/apt/sources.d (directory)w

** Week Two Notes
- Ubuntu is part of the Debian family. version in use for this course is ubuntu 20.04 LTS. The LTS means long term support meaning you have access to updates.
- Virtual box is a type of hypervisor ( a virtual machine monitor) that allows you to create and run VMs on your computer. Its free and open source.
- Vagrant is an open source tool that helps manage VM environments in a consistent and easy to use manner. IT provides a software layer between the virtualization tool (virtual Box, Docker, etc.). The main purpose is to specify the setting up and managing virtual development environment.
-WSL provides a Linux environment integrated with Windows; it is not a traditional VirtualBox VM. Vagrant manages VMs, while VirtualBox actually creates and runs the VM. The VM has its own OS, hostname, IP address, network interfaces, and configuration, so it behaves like a separate computer running on the same physical laptop.
- Types of processes include:
 parent processes(leads to the creation of more processes), child process, orphaned Process(process who do not have parents possibly they have been terminated so they belong to the main grand parent), zombie process (dead processes that have completed their execution and have been terminated but still find them self running), lastly we have daemon processes which run are those running in the background.

- Networking lessons:
  A reachable port doesn't mean the service behind it is ready. 
  A running VM doesn't mean the services inside it are ready.
-learn more about virtual memory and resident memory and swap files(an extension of your ram where when your ram is filled up it stores things there and then access then later on).
- Most applications come with a makefile which contains instructions for how an application should be compiled from the source code.
